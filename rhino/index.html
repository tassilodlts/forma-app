Describe it. Amphion models it in Rhino.

An AI modeling agent for architects. Type what you want, and Amphion builds real, editable Rhino geometry: massing, walls, slabs, roofs, stairs, openings. Then render your view in one click.

Things you can ask

  • “Build a 3 storey residential block, 20 x 12 m, with 35 cm exterior walls, slabs and a gable roof.”
  • “Add balconies 1.5 m deep to every floor of the south facade.”
  • “Cut 1.2 x 1.4 m windows every 3 m into the selected wall, sill at 0.9 m.”
  • “Array these columns on a 6 m grid, 5 by 3.”
  • “Make a stair from ground floor to first floor next to the entrance.”
  • “Put everything on proper layers and name the floors.”

Install

Mac (Rhino 7 or 8)
  1. Download Amphion.rhp.
  2. Drag the file onto the open Rhino window. Rhino installs it and keeps it loaded.
  3. Type Amphion in the command line to open the panel.
Windows (Rhino 7 or 8)
  1. Download Amphion.rhp.
  2. Drag it into Rhino, or use Tools › Options › Plug-ins › Install.
  3. Type Amphion to open the panel, or AmphionAsk to ask from the command line.

Rhino 8: also available as package amphion.yak.

Questions

Does it change my model without asking?

Amphion only touches what you ask for. New geometry goes on layers under “Amphion”. “Undo last edit” in the panel removes everything the last request did, and Rhino's own Undo works step by step.

Which AI does it use?

Amphion picks a strong model for modeling with tools. With your own key it uses Claude (Anthropic) or OpenAI directly, billed to your account.

Is my model sent anywhere?

Only what the agent needs: a list of objects with layers and sizes, and a viewport image when it checks its work or when you render. Your file is never uploaded and nothing is used for training.

What about Revit, SketchUp or Archicad?

Amphion's own app does plans, sections and BIM export. See Amphion.
