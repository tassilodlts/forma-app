Rhino to Blender: import and render in 5 minutes

Blender is free, renders with Cycles at production quality and is a good partner for Rhino. The only tricky part is the transfer: units, render meshes and normals. Here is the short, reliable route.

Updated 9 November 2026 · Amphion 3D

Before you export: three checks in Rhino

  1. Units. Work in metres if you can (Units). Blender's default unit is the metre, so a model in metres comes in at the right size. A model in millimetres comes in 1000 times too big and needs a scale of 0.001.
  2. Render meshes. Blender only sees meshes. Switch a viewport to Rendered or Shaded once so Rhino builds the render meshes, then save. For curved surfaces raise the quality under Options › Mesh › Custom (for example max angle 10 to 15°) or round shapes will show facets.
  3. Normals and closed solids. Use Dir to flip faces that point inwards. Inverted normals show up in Blender as black or see-through faces.

Route A: open the .3dm directly (recommended)

  1. In Blender 4.2 or newer, open Edit › Preferences › Get Extensions and search for “Rhino”. Install the free Import Rhinoceros 3D add-on (import_3dm). In older versions install the add-on zip from its GitHub release under Add-ons › Install.
  2. File › Import › Rhinoceros 3D (.3dm), then pick your file.
  3. Layers arrive as collections and Rhino materials as basic Blender materials. Blocks become linked instances, which keeps file size down.

This route keeps the most structure and is the fastest when you repeat the import after design changes.

Route B: OBJ or FBX

  1. Select the objects and use Export Selected to OBJ. In the OBJ options choose Export Rhino object names as OBJ groups or layers as groups, and polygon meshes with the quality you need.
  2. In Blender: File › Import › Wavefront (.obj). Set Forward and Up axes so that Z stays up (Rhino and Blender both use Z up, so Y forward, Z up is usually right).
  3. Use FBX if you need cameras or a single file for many objects; use OBJ if you want the most predictable result.

Clean up in Blender (one minute)

  • Select all, Mesh › Clean Up › Merge by Distance with a small distance (0.0001 m) to weld the seams between Rhino surfaces.
  • Right click › Shade Auto Smooth so curved parts look smooth and flat walls stay crisp.
  • Check the scale with the N panel: a 3 m storey should read 3 m.

Render with Cycles

  1. Render engine: Cycles, device GPU if you have one (Metal on Apple Silicon, OptiX or CUDA on NVIDIA).
  2. Light: in World, use the Sky Texture (Nishita) for a physical sun and sky, or an HDRI from a CC0 library for real context light.
  3. Camera: match your Rhino view. 24 to 35 mm for exteriors, 18 to 24 mm for interiors, camera at 1.6 m, and enable Shift instead of tilting to keep verticals straight.
  4. Colour management: View Transform AgX (Blender 4) or Filmic, Look medium contrast.
  5. Samples: 128 to 256 with the denoiser on (OpenImageDenoise). Interiors with small windows need more samples or a larger light portal.
  6. Materials: replace the imported colours with a few real materials: plaster with slight roughness variation, glass with Transmission 1.0, timber with an image texture. Five good materials beat fifty flat ones.

Questions

Can Blender open Rhino .3dm files?

Yes, with the free Import Rhinoceros 3D add-on (import_3dm). It brings in layers as collections, materials and block instances. Rhino must have saved render meshes in the file.

Why is my Rhino model huge or tiny in Blender?

The units differ. Blender works in metres; a Rhino model in millimetres comes in 1000 times too large. Scale by 0.001 and apply the scale, or switch the Rhino file to metres before export.

Why do curved surfaces look faceted?

The render mesh is too coarse. Raise the mesh quality in Rhino (Options, Mesh, Custom) before saving or exporting, then import again.

OBJ or FBX from Rhino to Blender?

OBJ is the most predictable for geometry and groups. FBX is useful when you need cameras or a single file with many objects. The native .3dm import usually beats both.

Do I lose my layers?

Not with the .3dm import, which turns layers into collections. With OBJ, export layers or object names as groups to keep the structure.
